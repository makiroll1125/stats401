Part 1: Select a Visualization

Masses in the Stellar Graveyard

Source

The visualization shows masses of black holes and neutron stars discovered through gravitational waves and electromagnetic observations. The interactive version provides multiple sorting modes, toggles for black holes/neutron stars and GW/EM detections, point-size controls, several layouts including standard and circle-pack views, and search.

The latest published version incorporates the expanding LIGO-Virgo-KAGRA catalog, and GWOSC currently provides the underlying event data publicly through both its catalog API and downloadable releases.

Part 2: Analyze the Original Visualization

Intended message: The visualization is trying to plot masses of black holes and neutron stars discovered through gravitational waves and electromagnetic observations. The first view communicates mass patterns for these groups and highlights a potential mass gap in the range of 2.5-5 solar masses where very few of these astronomical objects are found.

Audience: The intended audience are astrophysicists / astronomers and researchers interested in understanding and visualizing black hole and neutron star merger events.

Tasks: Viewers should be able to compare objects or merger events (compare values), determine final object mass after merge (determine values), notice trends in the masses of these objects (identify trends / explore patterns), find outliers, search for certain merger events (searc).

Part 3: Critique the Visualization

Strengths: 1. Class attributes are easy to distinguish. Four vibrant distinct colors are used to separate all four classes (merger BHs, merger neutron stars, EM BHs, EM neutron stars). 2. Four views allows different visualizations of the relationships of the data. 3. Interaction allows users to customizably sort both objects (gravitational waves and electormagnetic) to identify or compare various relationships. 4. In view 1 (standard), despite the large amount of data, the visualizaiton does a great job of managing overplotting / complexity by using small point marks, opaque / slightly transparent points, thin lines, and tooltips to display additional relevant data instead of encoding them into attributes. 5.

Weaknesses: 1. In the standard view, mass is double encoded (y-axis and area of point marks) which can be redundant. 2. Circle pack, circle links, and nodes views all suffer heavily from complexity (the classic "hairball" problem) and are functionally useless. 3. circle pack, circle links, and nodes are force-directed so their plots take a bit to finalize and are nondeterministic. 3. Bad algorithm causes slowness in force-directed views. 4. Toggling objects (black holes) does not remove their links. 5. There are no options for plotting other variables (ex. final mass, mass 1, mass 2, redshift) so it's not possible to determine other potentially useful relationships.
