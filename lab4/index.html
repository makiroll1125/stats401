Lab 4: Cleaning Web Data for Visualization

Tweet sentiment by keyword

Each circle is a keyword. Position and color show average sentiment; height and size show tweet count.

Analysis

Sentiment analysis was performed using the CardiffNLP Twitter-RoBERTa model. Mentions and URLs were replaced with the model's recommended placeholders before inference. This analysis uses a Kaggle collection of 11,370 English-language tweets organized around disaster-related keywords. I removed records without usable IDs or text, removed duplicate rows and IDs, normalized text, converted encoded spaces in keywords, parsed numeric fields, and assigned explicit values to missing keyword and location entries. The chart compares the 30 most frequent qualifying keywords (at least 25 tweets each). Horizontal position and color encode mean sentiment score, calculated as positive probability minus negative probability; vertical position and circle size encode tweet count. All 30 displayed keyword groups have negative average scores. Among them, airplane accident, traumatised, and mass murder are the most negative, while thunderstorm is closest to neutral. Group sizes also vary, with thunderstorm appearing most often among the displayed terms.
